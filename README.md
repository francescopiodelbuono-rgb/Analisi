# Analisi Portafoglio ETF

Progetto Python per analizzare un portafoglio ETF settoriale rispetto a un benchmark MSCI World.

## Obiettivi

- Download prezzi storici ETF
- Pulizia dati finanziari
- Calcolo rendimenti e volatilità
- Analisi drawdown
- Confronto con benchmark
- Calcolo Sharpe Ratio
- Stima VaR storico e parametrico
- Ottimizzazione portafoglio con frontiera efficiente

## Tecnologie

- Python
- Pandas
- NumPy
- Matplotlib
- yfinance
- SciPy
